# Glossary

| Term | Definition |
|---|---|
| **3DMM** | 3D Morphable Model — a parametric model that can generate 3D face meshes from a low-dimensional parameter vector |
| **Blendshape** | A pre-defined mesh deformation (morph target) that can be blended with others via weight coefficients |
| **CVAE** | Conditional Variational Autoencoder — a generative model that learns a latent representation conditioned on input labels |
| **Coarticulation** | The phenomenon where a phoneme's articulation is affected by preceding and following phonemes |
| **CTC** | Connectionist Temporal Classification — a loss function for sequence-to-sequence problems with unknown alignment |
| **DataTexture** | A Three.js data structure that packs arbitrary floating-point data into a GPU texture buffer |
| **ExpressionSampler** | GNM's built-in CVAE that maps 20 semantic emotion labels to 383 expression coefficients |
| **FLAME** | A popular parametric head model (Face Learning and Motion Estimation) |
| **Forced alignment** | The task of determining exact temporal boundaries of phonemes in an audio recording given the transcript |
| **G2P** | Grapheme-to-Phoneme — converting written text to phonetic transcription |
| **GNM** | Generative Anthropomorphic Model — Google's parametric 3D head model |
| **HuBERT** | Hidden-Unit BERT — a self-supervised speech representation model |
| **MoE** | Mixture of Experts — a neural architecture where different "expert" sub-networks are activated per token |
| **Morph target** | A stored vertex offset that, when applied with a weight, produces a specific deformation |
| **PCA** | Principal Component Analysis — dimensionality reduction technique used to build parametric models |
| **SLM** | Small Language Model — a compact LLM suitable for local/edge deployment |
| **Slerp** | Spherical linear interpolation — smooth interpolation between orientations or normalized vectors |
| **TSL** | Three Shading Language — Three.js's node-based shader system that compiles to WGSL |
| **Viseme** | The visual equivalent of a phoneme — the mouth shape used to produce a particular speech sound |
| **VOCASET** | A 4D head scan dataset (MPI-IS) with synchronized audio, registered to FLAME topology |
| **WebGPU** | Modern web graphics API providing low-overhead GPU access |
| **WGSL** | WebGPU Shading Language — the shader language for WebGPU |
